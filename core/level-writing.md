# 성취수준 진술 (교과 불변)

> 준거 ① — 교수·학습 **투입 전**에 확정해야 하는 준거.
> 수업 목표·평가 요소·채점기준·세부능력 및 특기사항 기록의 근거가 된다.
>
> 준거 ② 분할점수는 `core/cut-score.md` 참조.

---

## 1. 성취수준의 3층 위계

```
성취기준별 성취수준     성취기준 1개 단위, A~E
   국가 개발 (KICE 보급본)          ※ 2015 개정의 '평가기준(상/중/하)'에 해당
        ↓
영역별 성취수준         영역 단위, 범주(지식·이해/과정·기능/가치·태도)별 A~E
   국가 개발 — 단, 과목에 따라 없을 수 있음
        ↓
학기 단위 성취수준      과목·학기 단위, A~E
   ★ 교사가 만든다. 수업·평가·기록의 최종 준거.
```

### 위층 재료가 없는 경우가 있다

판단 기준은 **공통/선택이 아니라 내용 영역 구분의 유무**다.

> "단, 고등학교 선택과목의 경우, 교과(과목)별 내용 체계의 특성에 따라 **영역 구분이 없는 과목**(국어, 영어 등)에서는 '영역별 성취수준'이 없음."
> — KICE 선택과목 성취수준 보급본, 주요 용어 설명

영역 구분이 있으면 영역별 성취수준이 개발되어 있고, 없으면 애초에 영역 단위가 존재하지 않는다.
공통과목은 대개 영역 구분이 있어 개발되어 있지만, **선택과목이라고 해서 반드시 없는 것은 아니다.** 교과마다 다르므로 실제 자료로 확인해야 한다.

> "선택과목의 내용 영역이 구분되어 있지 않은 교과의 경우, 영역별 성취수준이 학기 단위 성취수준에 해당한다고 볼 수 있으므로, **성취기준별 성취수준을 바탕으로 학기 단위 성취수준 개발 방법을 준용하여 영역별 성취수준을 개발하여 활용**한다." — KICE 선택과목 성취수준 보급본

따라서 학기 단위 성취수준을 만들 때 **두 경로로 갈린다.**

| 과목 | 영역별 성취수준 | 학기 단위 성취수준 만드는 법 |
|---|---|---|
| **있음** (`has_area_levels: true`) | 국가 개발본 존재 | §3의 세 방식(㉮㉯㉰) 중 선택 |
| **없음** (`has_area_levels: false`) | 없음 | 성취기준별 성취수준에서 **직접 종합**. §3-㉯ 재구성 방식을 준용 |

각 과목의 `has_area_levels` 값은 `subject/subject.yaml`에 있다.

## 2. 진술의 원리

### 수준을 가르는 세 축

| 범주 | 무엇으로 수준을 구분하는가 |
|---|---|
| **지식·이해** | 개념의 **위계**, **이해의 깊이**, 지식 **전이** 정도 |
| **과정·기능** | **수행 정도**, **맥락·상황 변인**(단순 ↔ 복잡, 단일 ↔ 다양) |
| **가치·태도** | **내면화** 정도, **실천·적용 범위** |

```
        지식·이해              과정·기능               가치·태도
높음 │ 높은위계·깊은이해·높은전이 │ 문제해결·복잡한상황·다양한맥락 │ 내면화·넓은적용·적극적실천
     │            ↕                      ↕                       ↕
낮음 │ 낮은위계·단순암기·낮은전이 │ 문제인식·단순한상황·단순한맥락 │ 약한반응·좁은적용·약한실천력
```

### 부사어 위계

부사어는 **제한적으로** 쓴다. 불가피하게 쓸 때는 수준 간에 일관된 사다리를 유지한다.

| 수준 | 부사어 |
|---|---|
| A | 정확하게 / 구체적으로 / 심층적으로 / 능동적으로 / 종합적으로 |
| B | 비교적 정확하게 / 적절하게 |
| C | 대략적으로 |
| D | 부분적으로 / 일부 |
| E | 제한적으로 |

> 이 사다리는 KICE 성취수준 개발진과 경기 표준화 평가도구 개발진이 공유·적용한 규약이다.
> **부사어만 바꾸고 내용이 같으면 수준 구분이 아니다.** 부사어는 보조 장치이고, 본체는 위 세 축의 실질적 차이여야 한다.

### 진술 3원칙

| 원칙 | 요구 | 위반 예 |
|---|---|---|
| **적절성·위계성** | 각 수준 학생이 보여줄 수행 특성을 구체적 지식·이해, 과정·기능, 가치·태도로, **수준별 위계를 갖추어** 진술 | A와 B의 차이가 "매우"뿐 |
| **명료성** | 이해하기 쉽고 간결·명확하게. 가급적 **관찰 가능한 외현 동사** 사용. 모호·추상적 표현 지양 | "깊이 있는 통찰을 지닌다" |
| **일관성** | 영역 내·영역 간·전후 학년(군)에서 수준별 진술을 비교할 때 수준 설정 기준이 일관 | 어떤 영역은 C에서 '유용성 인식', 다른 영역은 D에서 |

**비교육적·부정적 표현은 쓰지 않는다.** 진술문은 학생·학부모에게 공지되고 기록의 근거가 된다.

### 진술 개발 절차

```
① 영역의 내용 체계와 성취기준(들)에서 지식·이해, 과정·기능, 가치·태도 내용 요소 추출 및 위계 분석
② 대상 성취기준이 포함한 내용 요소의 수준 분석
③ 내용 요소의 복합성을 고려해 3수준 또는 5수준 진술문 개발
   — 세 범주를 각각 구분한 뒤 복합적으로 구성한다
④ 작성 후 영역 간 수준 진술 정도, 전후 학년(군) 위계 점검
```

> ③에서 주의: 교과·영역 특성상 **가치·태도가 성취기준에 명시되지 않아도**, 교육과정 취지를 살려 영역 내 성취수준에 반영해야 한다. 반대로 교과·영역에 따라 특정 수준에서 일부 범주가 나타나지 않을 수도 있다.

## 3. 학기 단위 성취수준 진술 방식

### ① 성취기준별 성취수준 중심

성취기준마다 대응해 진술한다.

- **장점** — 수업·평가의 준거로 직접 쓰기 쉽다. 학기당 성취기준 수가 적을 때 유용.
- **단점** — 학기 전체 수행 능력을 조망하기 어렵고, 모든 성취기준을 평가해야 한다는 부담.

### ② 영역별 성취수준 중심

한 학기 세 범주를 체계적으로 조망할 수 있고 학생 수준을 종합 파악하기 좋다. 단, 성취기준과의 직접 연관 파악이 어렵다. 세 하위 방식이 있다.

> ### 기본 전제 — 2022 개정에서 **과목 = 한 학기**다
>
> 고교학점제의 학기별 이수에 맞추어 과목이 한 학기 완결로 설계되어 있다.
> 공통과목이 과목명 뒤에 1·2를 붙여 나뉜 것(각 4학점, 한 학기 분량)이 그 설계다.
>
> 따라서 **그 과목의 성취기준 전부가 그 학기의 범위**이며, 영역 커버리지는 대개 100%다.
> 영역별 성취수준이 있는 과목이라면 **재진술 없이 그대로 병합·재구성해도 된다.**
>
> ### 예외 — 실제 편성이 과목 전체와 다를 때
>
> 다만 다음 경우에는 실제 편성 범위를 확인해야 한다.
>
> - 학교가 한 과목을 **두 학기에 나누어** 운영하는 경우 (예: 4학점 과목을 1·2학기 주 2시간씩)
> - 1년 단위로 설계된 과목을 학기별로 나누어 평가하는 경우 (2015 개정 과목 등)
>
> 경기도교육청은 "여러 영역이 전체 교과목에서 적용되는 경우 **한 학기에 해당하는 내용 요소와 수준을 재진술하는 작업이 수반**된다"고 안내한다.
>
> 이때는 영역별로 `편성 성취기준 수 / 영역 전체 성취기준 수` 를 세어, 일부만 편성된 영역이 있으면 **그 학기 범위로 재진술한다.** 그대로 병합하면 다른 학기에 배울 성취기준의 내용까지 준거에 들어간다.

**㉮ 범주별 병합** — 영역별 성취수준의 세 범주 내용을 수준별로 그대로 합친다.

```
(가)~(마) 영역의 A 특성 통합 기술  →  학기 단위 A
(가)~(마) 영역의 B 특성 통합 기술  →  학기 단위 B
...
```
진술이 쉽지만, **범주별 비중이 동등하지 않은 교과에서 덜 중요한 범주가 과대 표현**될 수 있다.

> **실무 주의 — 분량.** 현장 평가계획을 확인해 보니 학기 단위 성취수준을 이 방식으로 만든 학교가 많았고,
> 서로 다른 시도의 진술문이 글자까지 같은 경우도 있었다. 성취기준이 10개를 넘는 과목에서 그대로 이어 붙이면
> **한 수준이 2,000자를 넘어 A~E 전체가 A4 6쪽 이상**이 되기도 한다. 준거는 수업·평가 중에 참조되어야 하므로
> 이 분량은 실패다. 성취기준 수가 많으면 ㉮로 초안을 잡되 **㉯로 압축하는 단계를 반드시 거친다.**

**㉯ 재구성** — 범주별로 흩어진 중복 표현을 하나로 묶어 영역별 내용으로 다시 쓴다.

> "다항식의 사칙연산의 원리를 안다." + "항등식의 성질을 안다."
> → "다항식의 사칙연산의 원리, 항등식의 성질을 안다."

간단명료해진다. **영역별 성취수준이 없는 과목은 이 방식을 성취기준별 성취수준에 적용**한다.

**㉰ 교과 역량 중심 재구성** — 내용 요소가 어느 교과 역량에 해당하는지 분석한 뒤 역량별로 종합한다.

- 교육 목표와 일관되게 평가 결과가 산출된다는 의의가 있다.
- 학기 수준에서 **교과 역량이 고루 등장하는지** 점검한다. 특정 역량의 진술문이 안 나오면 내용 체계·성취기준부터 재검토한다.
- 역량별로 재구성할 때 동일 수준이 아닌 내용이 섞이면 재배치할 수 있다. 이때 학생 수준과 영역 간 형평성을 고려한다.

## 4. 최소 성취수준 진술문

고교학점제 미이수 판정의 근거가 되므로 별도로 다룬다.

> **작성 의무 범위는 공통과목이 확실하고, 그 위는 확인이 필요하다.** 상위 안내서는 이수 기준을
> 전 과목에 적용한다고 하지만 일부 학교 규정은 보장지도를 "공통과목은 … 실시하며"로 적는다
> (`core/asa-rules.md` §8의 불일치 표). **"의무"라고 단정하지 말고 소속 시도 지침을 확인하도록 안내한다.**

### Range PLD vs Target PLD — 결정적 구분

```
성취수준 E 진술문        성취율 40~60% 구간 전체의 특성   (Range PLD)  ← 공통과목 기준
최소 능력의 수행 특성    정확히 40% 지점의 전형적 수행    (Target PLD)  ★
```

교사가 가장 많이 혼동하는 지점이다. E 수준 진술문을 그대로 옮겨 적으면 최소 성취수준 진술문이 되지 않는다.

> 예 — 성취기준별 성취수준 E: *"간단한 다항식의 사칙연산을 할 수 있다"*
> → 최소 능력의 수행 특성: *"㉮ 간단한 다항식의 **덧셈과 뺄셈**을 할 수 있다"*
>
> '사칙연산' 중에서도 '덧셈·뺄셈'만 할 수 있으면 E에 가까스로 도달한 것으로 본다.

### 구성

| 칸 | 내용 |
|---|---|
| 영역 | 개발 단위. 내용 체계의 **영역 단위**로 개발 |
| 영역별 성취수준 (E) | 범주별로 영역별 성취수준의 E(3단계는 C)를 **그대로 준용** |
| 성취기준별 성취수준 (E) | 성취기준별 성취수준의 E를 **그대로 준용** |
| **최소 능력의 수행 특성** | 40% 지점의 수행 특성. **㉮ ㉯ ㉰** 로 번호를 매겨 열거 |

### 진술 요령

- 성취기준별 성취수준 E의 내용 요소를 확인하고, **선수학습 내용 요소와의 관계**, 교과서 기초 문제 등을 활용한다.
- 관찰 가능한 단위 행동으로 쪼갠다. "~을 안다"보다 "~을 말할 수 있다 / 구할 수 있다 / 찾을 수 있다".
- 이 진술문이 곧 **최소 성취수준 확인 문항의 출제 근거**이자 **보장지도의 목표**가 된다.

## 5. 성취수준별 최소 능력자(MCP) 수행 특성

> MCP = Minimally Competent Person, **각 성취수준에 가까스로 도달한 학습자**

최소 성취수준 진술문이 40% 지점만 다룬다면, MCP 진술은 **모든 기준 성취율 지점(90·80·70·60·40)** 을 다룬다.

### 왜 필요한가

MCP 진술이 **문항의 출제 범위를 정의**한다.

```
성취수준 A 최소 능력자의 특성  ──┐
                                 ├─ 이 사이가 '성취수준 B를 대표하는 문항'의 출제 범위
성취수준 B 최소 능력자의 특성  ──┘
```

그리고 이 사슬로 이어진다.

```
MCP 진술 → 문항 출제 범위 확정 → 예상 정답률 추정 → 분할점수 산출
```

**MCP 진술을 건너뛰면 그 아래 전부가 근거를 잃는다.**

### 작성 요령

- 성취기준별 성취수준 진술문에서 출발해, 각 수준의 **최저선**에 있는 학생이 무엇을 할 수 있는지로 좁힌다.
- 성취기준별 성취수준보다 **약간 낮게** 진술되는 것이 정상이다. (그 수준의 평균이 아니라 하한이므로)
- 부사어 위계와 수행 동사 위계를 준용한다.
- **교과·학년 협의회에서 합의**한다. 절대적 기준이 아니라 합의 결과이며, 학교마다 다를 수 있다.
- 문항을 현장에서 변형해 쓸 때 **내용의 복잡성과 깊이를 조절하는 기준**으로도 쓴다.

## 6. 자체 점검 목록

- [ ] 인접 수준(A↔B, B↔C, …)의 차이를 **한 문장으로 말할 수 있는가?** 못 하면 수준 구분이 안 된 것이다
- [ ] 차이가 부사어뿐인 곳은 없는가
- [ ] 세 범주(지식·이해 / 과정·기능 / 가치·태도)가 모두 반영되었는가
- [ ] 관찰 가능한 외현 동사를 썼는가
- [ ] 모호·추상적 표현, 비교육적·부정적 표현이 없는가
- [ ] 영역 간 수준 설정 기준이 일관되는가
- [ ] 성취기준의 범위를 벗어난 내용이 들어가지 않았는가
- [ ] 학기 단위 성취수준이 해당 학기 성취기준 전체를 포괄하는가
- [ ] 최소 성취수준 진술문이 Range가 아닌 **Target(40% 지점)** 을 기술했는가
- [ ] MCP 진술이 각 기준 성취율의 **최저선**을 기술했는가
