# 분할점수 (교과 불변)

> 준거 ② — **평가도구를 개발한 뒤, 평가를 시행하기 전에** 확정하고 공지해야 하는 준거.
> 준거 ① 성취수준 진술은 `core/level-writing.md` 참조.

---

## 1. 정의

**분할점수(cut score)** — 평가 과정에서 학생의 성취도 또는 수행 정도의 차이를 구분하기 위한 **평가 척도상의 준거점수**.

5단계 평정 과목은 성취도를 가르는 분할점수가 5개(A/B, B/C, C/D, D/E, E/미도달) 필요하다.

준거점수에 해당하는 수행 능력은 **각 성취수준의 최소 능력**으로 표현된다. 따라서 최소 성취수준(성취율 40~60%)의 준거점수는 **성취율 40%에 해당하는 척도상의 점수**다.

---

## 2. 두 가지 산출 방식

두 방식의 **기준 성취율은 동일**하다(90 / 80 / 70 / 60 / 40). 차이는 **기준 성취율을 원점수와 같은 척도로 보느냐**다.

| | **성취수준별 고정분할점수** | **성취수준별 추정분할점수** |
|---|---|---|
| 방식 | 기준 성취율을 100점 척도에 1:1 대응. 90/80/70/60/40**점**으로 고정 | 교과 특성·문항 난이도를 고려해 교사 협의로 각 기준 성취율에 해당하는 점수를 **추정** |
| 전제 | 평가 문항이 교수·학습 목표와 내용을 **100% 대표**해야 함 | 1:1 대응 제약 없음 |
| 평가도구 제작 | **더 까다롭다.** 성취수준과 문항 난이도를 일관되게 맞출 고도의 전문성 필요 | 상대적으로 부담이 적다 |
| 업무 부담 | 낮음 (별도 산출 절차 없음) | **높음** (라운드 진행·협의 필요) |
| 학생·학부모 안내 | 산출 방법 공지로 갈음 | 설정 과정의 **객관성에 대한 안내 및 대응 방안** 필요 |

### 어느 쪽을 고를 것인가

- 고정분할점수를 쓰려면 **문항이 교수·학습 목표와 내용을 완벽히 대표**해야 한다. 학생이 수업으로 성취한 정도와 평가에서의 수행 정도가 같다고 볼 수 있어야 하기 때문이다.
- 추정분할점수는 문항 출제의 자유도가 크지만, **절차와 공지 의무**가 따른다.
- 결정은 **학기 초 평가 계획 단계**에서 하고 학업성적관리위원회 심의를 받는다.

---

## 3. 추정분할점수 — 지필평가 7단계

| 단계 | 내용 |
|---|---|
| 1 | **학기 단위 성취수준 특성 확인** — 교수·학습 종료 후 학생이 도달해야 할 수준 숙지 |
| 2 | **성취수준별 최소 능력 특성 합의** — 각 기준 성취율(90·80·70·60·40)에 가까스로 도달한 MCP의 수행 특성을 개념화·합의 |
| 3 | **문항 검토** — 성취기준, 성취기준별 성취수준, 문항 내용, 난이도, 배점 확인 |
| 4 | **문항 범주화** — 문항 유형(선택형/논술형) × 난이도(상/중/하) → **최대 6개 범주** |
| 5 | **문항 범주별 예상 정답률 추정** — 성취수준별 MCP의 범주별 정답률을 5% 단위로 추정 (교사 개별 평정) |
| 6 | **교사별 평정 결과 종합 및 논의** — 교사별 분할점수 산출 및 검토 |
| 7 | **분할점수 산출** — 교사별 평균 산출. **평가 시행 전 공지** |

> **5~6단계는 최소 2회 반복**한다. 시스템상 1라운드로도 확정은 가능하나 2라운드 이상을 권장한다.

### 입력 검증 규칙 (자동 검출 대상)

| # | 규칙 | 위반 시 |
|---|---|---|
| C1 | 예상 정답률은 **5% 단위**로 입력. 단 E 수준만 1% 단위 허용(예: 49%) | 입력 거부 |
| C2 | **하위 수준의 예상 정답률이 상위 수준보다 높을 수 없다** (단조성) | 입력 거부 |
| C3 | **'쉬움' ≥ '보통' ≥ '어려움'** 범주 순으로 예상 정답률이 유지되어야 한다 | 입력 거부 |
| C4 | 상위 수준과 차하위 수준의 예상 정답률 차이가 **20%p 이상**이면 경고(적색) | 재검토 |
| C5 | 동일 난이도·동일 성취수준에서 **교사 간 차이가 20%p 이상**이면 경고(적색) | **교사 간 협의 필수** |
| C6 | 모든 입력 교사가 마감해야 확정 가능 | 확정 불가 |

> C4·C5는 오류가 아니라 **협의 신호**다. 값을 억지로 맞추지 말고, 왜 갈렸는지 논의한 뒤 조정한다.

### ⚠ 금지

**최소 성취수준 미도달 학생 비율을 줄이려고 E 수준 분할점수를 임의로 낮게 산정하지 않는다.**
(`core/asa-rules.md` R2) 이수 판정의 신뢰성이 무너진다.

## 4. 추정분할점수 — 수행평가 6단계

| 단계 | 내용 |
|---|---|
| 1 | 학기 단위 성취수준 특성 확인 |
| 2 | 성취수준별 기준 성취율 수행 특성 개념화 — 각 수준 **최저선** 학생의 수행 능력 |
| 3 | 수행평가 검토 — 성취기준별 성취수준 및 채점기준 검토 |
| 4 | 성취수준별 예상 점수 추정 — 기준 성취율 학생이 획득할 점수 |
| 5 | 교사별 예상 점수 추정 결과 협의 |
| 6 | 분할점수 산출 — **평가 시행 전 공지** |

> 전체 영역 총점 기준으로 산출하거나 영역별로 산출할 수 있다. 교사 간 협의 후 대표 교사 1인이 입력한다.

### 채점기준표에서 분할점수를 직접 얻는 법

수행평가·논술형은 채점기준표에 **성취수준 × 수행 수준 × 배점**을 연계해 두면 분할점수가 자동으로 도출된다.

> **각 수준 MCP가 평가 요소별로 받는 점수의 합 = 그 수준의 분할점수**

예시 — 채점기준표

| 문항 | 평가 요소 | 성취수준 | 배점 |
|---|---|---|---|
| 1 | 평가요소1 | A–C | 6점 |
| | | D | 5 / 4점 |
| | | E | 3 / 2 / 1점 |
| 2 | 평가요소2 | A | 8 / 7 / **6점** |
| | | B | 5 / **4점** |
| | | C | 3점 |
| | | D–E | 2점 |

- A 수준 MCP: 평가요소1에서 6점 + 평가요소2에서 6점 = **A/B 분할점수 12점**
- B 수준 MCP: 6점 + 4점 = **B/C 분할점수 10점**

→ 어느 학생의 수행평가 점수가 11점이면 **성취수준 B**로 판별한다.

| A/B | B/C | C/D | D/E | E/미도달 |
|---|---|---|---|---|
| 12 | 10 | 9 | 6 | 3 |

**이 방식의 이점** — 점수만으로 수준 판별이 가능해지고, 성취수준에 따른 피드백을 바로 붙일 수 있다.

### ⚠ 금지

**기본점수만으로 성취율 40%에 도달하게 하지 않는다.** (`core/asa-rules.md` R1)
'최소 능력의 수행 특성'에서 제시한 수행 수준을 영역별 성취율 40%에 해당하는 채점기준과 연계하고, **기본점수는 이보다 낮게** 부여한다.

## 5. 학기말 최종 분할점수

지필평가·수행평가의 분할점수를 산출하면 **학기말 추정분할점수가 자동 산출**된다(교육정보시스템).

- 학기말 최종 분할점수 산출 → 학업성적관리위원회 심의 → 학기말 성적처리 → 가정통신문 발송 → 성적 담당자 입력
- 추정분할점수 산출이 완료되면 문항정보표 내 **성취기준과 난이도는 수정할 수 없다.** 수정이 필요하면 산출을 취소한 뒤 진행한다.

---

## 6. 행정 절차와 공지 시점

**평가 시행 전에** 성취수준별 추정분할점수가 산출된 후 안내해야 한다. 심의 시기는 다음과 같다.

| # | 심의 시점 |
|---|---|
| ① | 평가 계획 수립 시 — **고정/추정 중 어느 방식을 쓸지 결정**할 때 |
| ② | 추정분할점수로 결정한 경우 — ㉮ 수행평가 실시 전 ㉯ 1차 지필평가 실시 전 ㉰ 2차 지필평가 실시 전 ㉱ 학기말 최종분할점수 산출 후 |

```
수행평가:  평가 계획 수립·결재 → 도구 개발 → 분할점수 산출 → 위원회 심의 → 평가 실시 → 가정통신문
지필평가:  출제 계획 수립·결재 → 도구 개발 → 분할점수 산출 → 위원회 심의 → 평가 실시 → 가정통신문
학기말:    최종 분할점수 산출 → 위원회 심의 → 성적처리 → 가정통신문 → 시스템 입력
```

> 고정분할점수는 별도 산출 과정이 없으므로 **산출 방법 공지로 대신**한다.

## 7. 체크리스트

- [ ] 수행평가 선행 작업을 했는가
- [ ] 지필평가 문항정보표를 입력·마감했는가
- [ ] 최소 능력자의 수행 특성을 개념화했는가 (`core/level-writing.md` §5)
- [ ] 예상 정답률 입력 시 **성취수준 간 차이가 20%p 미만**인가
- [ ] 동일 난이도·동일 성취수준에서 **교사 간 차이가 20%p 미만**인가
- [ ] 20%p 이상 차이 시 **교사 간 협의**를 했는가
- [ ] 상위 수준 예상 정답률이 하위 수준보다 **높은가**
- [ ] '쉬움' 범주 예상 정답률이 '보통'·'어려움'보다 **낮지 않은가**
- [ ] 예상 정답률 추정을 **2라운드 이상** 진행했는가
- [ ] 담당 교사 **모두**가 마감했는가
- [ ] **평가 시행 전에** 학생·학부모에게 공지했는가
- [ ] 학업성적관리위원회 심의를 받았는가
