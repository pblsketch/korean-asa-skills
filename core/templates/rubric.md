# 채점기준표

> 수행 수준은 **과제의 복잡성·난이도**가 아니라 **학생의 수행**으로 기술한다. (core/asa-rules.md R4)
> 각 수준은 교과 전문성으로 구분 가능한 **질적 기준**을 가져야 한다.

> 수행 수준의 차이가 드러나지 않으면 수준을 **합치거나 늘릴 수 있다**(3~5단계).
> 하나의 성취수준에 복수 배점을 두어도 된다(A 최대/중간/최소 능력자 → 8/7/6점).
> ※ **공통과목**은 학업 성취율 40% 미만의 수행 수준 및 배점을 생략한다. (선택과목은 성취율 이수 기준이 없어 해당 없음)

## 채점 시 고려 사항
- 인정 범위(예시 답안·유사 정답)
- 풀이 과정에 따른 부분 점수 / 단계별 점수
- 예시 답안과 달라도 타당성을 갖추면 인정할 범위

## 점검
- [ ] 성취기준이 요구하는 도달 목표에 맞게 제시되었는가
- [ ] 인지적·정의적 성장과 발달 과정을 파악할 수 있는가
- [ ] 평가 요소·척도·세부 내용(기대 수행·예시 답안)이 모두 제시되었는가
- [ ] 각 수준 진술문이 기대 수행을 구체적으로 기술해 **수준별 차이가 분명한가**
- [ ] 학기 단위 성취수준과 연계되는가
- [ ] (공통과목) 기본점수만으로 성취율 40%에 도달하지 않는가 (R1)
- [ ] 임의적 배점·과도한 기본점수가 없는가
