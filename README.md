# 성취평가제 교사 지원 스킬

2022 개정 교육과정 **성취평가제**로 평가를 설계하고, 문항을 만들고, 결과를 분석하는 일을 돕는 Claude Code 스킬 묶음입니다.

성취평가제에서 가장 품이 많이 드는 일은 문항을 쓰는 것 자체가 아니라, **"이 문항이 어느 성취수준을 재는지"를 근거를 갖춰 설명하는 일**입니다. 학기 단위 성취수준을 진술하고, 성취수준별 최소 능력자의 수행 특성을 합의하고, 채점기준을 성취수준과 연계하고, 분할점수를 산출하는 그 사슬 전체를 성취기준 코드 하나에서 시작해 이어 줍니다.

> **국어과 버전입니다.** 수학·영어·사회·과학 등 다른 교과는 이 저장소를 포크해서 만듭니다 → [FORKING.md](FORKING.md)

---

## 이런 분께

- 고교학점제 전면 시행으로 **미이수 판정**을 실제로 해야 하는데, 최소 성취수준 진술문을 어떻게 쓸지 막막한 분
- A~E 문항을 골고루 내라는데 **E 수준 문항을 어디까지 쉽게** 만들어야 하는지 감이 안 오는 분
- **추정분할점수** 라운드를 돌려야 하는데 절차와 검증 규칙이 헷갈리는 분
- 시험이 끝나고 **정답률만 보고 넘어가기** 아쉬운 분
- 교과협의회 상호 검토를 형식적으로만 하고 있는 게 마음에 걸리는 분

## 무엇을 하나요

세 개의 스킬이 성취평가 절차를 나눠 맡습니다.

### `asa-guide` — 평가의 준거를 세웁니다

성취평가제 질문에 답하고, 성취기준을 분석해 평가 요소를 뽑고, **학기 단위 성취수준**과 **최소 성취수준 진술문**을 만들고, 학기 평가계획서를 씁니다.

```
"공통국어1 1학기 평가계획 세워줘. 성취기준은 7개 편성했어."
"최소 성취수준 진술문 만들어줘. 미이수 대비해야 해."
"추정분할점수 절차 알려줘. 교사 3명이 예상 정답률을 이렇게 냈는데 괜찮을까?"
```

### `asa-item` — 문항을 만듭니다

**선다형**(성취수준별 A~E 표적 5문항 세트) · **서·논술형** · **수행평가 과제**를 만들고, 채점기준표와 성취수준별 분할점수까지 냅니다.

```
"[10공국1-01-02] 로 성취수준별 선다형 문항 세트 만들어줘."
"이 성취기준으로 수행평가 과제랑 채점기준표 만들어줘."
"작년에 낸 이 문항들 검토해줘."          ← 검토 모드
```

### `asa-analyze` — 결과를 되돌립니다

정답률과 답지반응 분포로 **평가도구 자체를 검증**하고, 오개념을 추론하고, 최소 성취수준 미도달 학생을 찾고, 피드백 문구와 다음 시험 개선안을 냅니다.

```
"1차 지필 결과 분석해줘. 문항정보표랑 정답률 붙일게."
"3번 문항 왜 이렇게 어려웠을까?"
"미도달 학생 몇 명이야? 보충지도 계획도 같이."
```

산출물은 **한글(HWP) 문서**로 나옵니다. 결재·인쇄가 바로 됩니다.

## 설치하기

### 1. 플러그인 설치

Claude Code에서 아래 두 줄을 실행하세요.

```
claude plugin marketplace add https://github.com/pblsketch/korean-asa-skills
claude plugin install korean-asa@korean-asa
```

### 2. 저장소 내려받기

성취수준 데이터를 만들려면 저장소가 로컬에 있어야 합니다.

```bash
git clone https://github.com/pblsketch/korean-asa-skills
cd korean-asa-skills
```

### 3. 성취수준 데이터 만들기 ★

**저장소에는 성취수준 원문이 들어 있지 않습니다.** 한국교육과정평가원의 저작물이라 재배포하지 않고, 각자 로컬에서 만들도록 했습니다.

먼저 아래 두 자료를 내려받아 저장소 폴더에 두세요. 두 파일 모두 **`.hwp`** 를 권합니다(PDF는 표가 페이지를 넘을 때 셀이 깨집니다).

| 자료 | 어디서 |
|---|---|
| 2022 개정 교육과정에 따른 고등학교 **국어과 공통과목** 성취수준 | 한국교육과정평가원 |
| 2022 개정 교육과정에 따른 고등학교 **국어과 선택과목** 성취수준 (현장 보급본) | 한국교육과정평가원 |

파일 이름은 `subject/subject.yaml` 의 `sources` 항목에 적힌 것과 맞춰 주세요. 다르면 그 항목을 고치면 됩니다.

그리고 이렇게 실행합니다.

```bash
python scripts/build_refs.py        # 성취수준 추출
python scripts/validate_subject.py  # 잘 됐는지 검사
```

성공하면 이렇게 나옵니다.

```
과목                   성취기준         영역별 성취수준
공통국어1                  14                6
공통국어2                  15                6
화법과 언어                 15                0
…
과목 11개, 성취기준 119개 → subject/data/standards
```

> `.hwp` 를 읽으려면 [claw-hwp](https://github.com/DoHyun468/claw-hwp) 플러그인이 필요합니다. 한컴오피스는 없어도 됩니다.

### 4. (선택) KICE 학생평가지원포털 연동

[학생평가지원포털](https://stas.moe.go.kr)의 평가도구 색인을 가져오면, 어떤 성취기준에 어떤 예시 평가도구가 있는지 바로 확인할 수 있습니다.

```bash
cp .env.example .env    # 본인 계정 입력
python scripts/stas_fetch.py --detail
```

> 첨부 파일 자동 다운로드는 지원하지 않습니다. 포털이 저작권 동의를 받은 뒤에 파일을 내주는데, 그 동의 절차를 스크립트가 대신 우회하지 않습니다. 색인의 과제 번호로 포털에서 직접 받으세요.

## 다루는 과목 (11개)

| 구분 | 과목 |
|---|---|
| 공통 | 공통국어1, 공통국어2 |
| 일반선택 | 화법과 언어, 독서와 작문, 문학 |
| 진로선택 | 주제 탐구 독서, 문학과 영상, 직무 의사소통 |
| 융합선택 | 독서 토론과 글쓰기, 매체 의사소통, 언어생활 탐구 |

전 과목 **성취도 5단계(A~E)** 입니다. 국어 교과(군)는 융합선택까지 5단계이고, 3단계는 체육·예술과 과학탐구실험뿐입니다.

> ⚠ **영역별 성취수준은 공통과목에만 있습니다.** 평가원은 선택과목 9종에 대해서는 성취기준별 성취수준만 개발했고, 국어 선택과목은 내용 영역 구분 자체가 없습니다(그래서 코드가 전부 `01`입니다).
> 학기 단위 성취수준을 만들 때 **공통과목과 선택과목의 경로가 다릅니다.** 스킬이 알아서 갈라 처리하지만, 알고 계시면 결과를 검토하실 때 도움이 됩니다.

## 폴더 구조

```
core/              성취평가제 규칙 — 교과가 바뀌어도 안 바뀌는 부분
  asa-rules.md       성취율·평정 단계·2/3 규칙·금지 규칙·학점이수
  level-writing.md   성취수준 진술 3층 위계·MCP·최소 성취수준
  cut-score.md       고정/추정 분할점수 절차와 검증 규칙
  result-analysis.md 결과 분석 프레임
  templates/         문항카드·채점기준표·문항정보표 등 양식 6종

subject/           국어과 팩 — 포크할 때 이 디렉터리만 교체합니다
  subject.yaml       과목 목록·코드 체계·시도 지침·원자료 (계약 파일)
  difficulty-levers.md   ★ 성취수준을 가르는 국어과 난이도 변수
  item-conventions.md    문항 형식·발문 관행
  misconceptions.md      오답·오개념 패턴
  data/              (직접 빌드, 저장소에 없음)

skills/            asa-guide · asa-item · asa-analyze
scripts/           빌드·조회·분석·수집·검증 도구
subject-template/  빈 교과 팩 (포크용)
```

**왜 이렇게 나눴나** — 성취평가제의 제도 규칙(성취율, 분할점수, MCP 개념)은 교과와 무관합니다. 교과마다 다른 건 성취기준과 "무엇이 난이도를 만드는가"뿐입니다. 그래서 둘을 갈라 놓았습니다. 덕분에 수학과 버전을 만들어도 엔진은 그대로 쓰고, 나중에 엔진이 개선되면 그것도 그대로 받아올 수 있습니다.

## 다른 교과로 만들기

포크한 뒤 `subject/` 하나만 채우면 됩니다.

```bash
python scripts/init_subject.py --id math --name "수학과"
python scripts/validate_subject.py    # 남은 TODO 를 짚어 줍니다
```

가장 중요하고 어려운 건 `difficulty-levers.md` — **그 교과에서 무엇이 성취수준을 가르는가**를 정리하는 문서입니다. 국어과에서는 (지문 부담 · 판단 지점 수 · `<보기>` 지원 정도 · 사고 조작 위계 · 선지 변별 거리) 다섯 가지였습니다. 수학이라면 (연산 단계 수 · 조건 개수 · 표현 형식 전환 · 역문제 여부)처럼 완전히 달라집니다.

도출 절차와 반자동 부트스트랩 사용법은 [FORKING.md](FORKING.md)에 있습니다.

## 자주 나오는 질문

**Q. 성취수준 데이터를 왜 저장소에 안 넣었나요?**
교육부·평가원·시도교육청의 저작물이기 때문입니다. 공개 저장소에 재배포할 근거가 확인되지 않아 각자 빌드하는 방식으로 했습니다. 해당 자료가 공공누리 제1유형으로 확인되면 함께 배포하도록 바꿀 예정입니다.

**Q. 분할점수를 스킬이 정해 주나요?**
아니요. 산출·검증·협의 안건 생성까지만 합니다. **분할점수 확정은 학업성적관리위원회 심의 사항**입니다.

**Q. 학생 성적 데이터를 넣어도 되나요?**
넣지 마세요. `asa-analyze` 는 **문항 단위 집계와 익명 분포만** 받습니다. 실명이 든 자료를 주면 익명화를 먼저 요청합니다.

**Q. 다른 시도교육청인데 쓸 수 있나요?**
됩니다. `subject/subject.yaml` 의 `jurisdiction` 블록만 고치세요. 기본값이 경기도교육청(선택형=오지선다, 서답형=논술형)으로 되어 있습니다.

**Q. 2015 개정 교육과정 자료도 되나요?**
성취수준 체계가 달라 그대로는 안 됩니다. 특히 **2022 개정에서 E는 40~60%이고 그 아래가 미도달**인데, 2015에서는 E가 60% 미만이라 미도달 개념이 없었습니다. 이 차이가 미이수 판정의 근거라 섞으면 안 됩니다.
