2022 개정 교육과정 **성취평가제**로 평가를 설계하고, 문항을 만들고, 결과를 분석하는 일을 돕는 Claude Code 스킬 묶음입니다.

## ⚠ 시작하기 전에 — 학생 개인정보

> **이름 · 학번 · 생년월일 · 주소 · 연락처 · 가족관계 · 타인 사진**

학생에게 지도하는 기준을 **교사 자신에게도 똑같이** 적용해야 합니다.

| | |

## 성취평가제가 교사에게 실제로 요구하는 것

성취평가제는 학생을 서로 비교하는 **규준참조평가(상대평가)** 가 아니라, 미리 정해 둔 준거에 비추어 판단하는 **준거참조평가(절대평가)** 입니다. 그래서 교사가 해야 할 일이 하나 늘어납니다.

> **평가도구를 만들기 전에 준거를 먼저 문서로 확정해야 합니다.**

준거는 두 종류입니다.

| | 준거 ① **성취수준 진술** | 준거 ② **분할점수** |
|---|---|---|
| 무엇 | 각 수준 학생이 무엇을 알고 할 수 있는지 | 성취도를 가르는 점수 |
| 언제까지 | 교수·학습 **투입 전** (학기 초) | **평가 시행 전** 공지 |
| 쓰이는 곳 | 수업 목표 · 평가 요소 · 채점기준 · 세특 기재 | 학기말 성취도 평정 |

이 도구는 그 두 준거를 세우고, 준거에 맞는 문항을 만들고, 결과를 다시 준거에 비추어 해석하는 사슬 전체를 **성취기준 코드 하나에서 시작해** 이어 줍니다.

### 알아 두면 좋은 용어

정책 문서에 나오는 표현 그대로 쓰되, 뜻을 함께 적었습니다.

| 용어 | 뜻 | 이 도구에서 |
|---|---|---|
| **성취기준** | 학생이 학습 후 할 수 있기를 기대하는 도달점. `[10공국1-01-02]` 같은 코드로 식별 | 모든 작업의 시작점 |
| **성취수준** | 성취기준에 도달한 정도를 A~E로 나누고, 각 수준 학생이 무엇을 아는지 기술한 것 | 평가원 개발본 119개를 내장 |
| ├ 성취기준별 성취수준 | 성취기준 1개 단위 (2015 개정의 '평가기준'에 해당) | 국가 개발본 사용 |
| ├ 영역별 성취수준 | 영역 단위. 지식·이해 / 과정·기능 / 가치·태도 범주별 | **공통과목에만 있음** |
| └ **학기 단위 성취수준** | 한 학기 전체를 포괄. **교사가 직접 만듦** | `asa-guide` 가 생성 |
| **성취율 / 기준 성취율** | 도달 정도를 백분율로 표시한 것 / 수준을 가르는 성취율 (90·80·70·60·40%) | 규칙으로 내장 |
| **성취도** | 최종 부여하는 A·B·C·D·E | 5단계 (국어 교과군 전 과목) |
| **최소 성취수준** | 성취율 **40% 이상 60% 미만** 구간 | 미이수 판정의 경계 |
| **최소 능력의 수행 특성** | 그중에서도 정확히 **40% 지점**의 전형적 수행 | 보장지도의 목표 |
| **성취수준별 최소 능력자(MCP)** | 각 수준에 가까스로 도달한 학생 | **문항 출제 범위를 정의** |
| **분할점수** | 성취도를 가르는 척도상의 점수 | 고정 / 추정 두 방식 |
| **과목 이수 기준** | 출석률 2/3 이상 **그리고** 학업 성취율 40% 이상 | 하나라도 미달이면 **미이수** |

### 성취율과 성취도 (2022 개정, 5단계)

| 성취율 | 성취도 |
|---|---|
| 90% 이상 | **A** |
| 80% 이상 ~ 90% 미만 | **B** |
| 70% 이상 ~ 80% 미만 | **C** |
| 60% 이상 ~ 70% 미만 | **D** |
| **40% 이상 ~ 60% 미만** | **E** |
| 40% 미만 | **미도달** → 최소 성취수준 보장지도 이수 시 E 부여 |

> ⚠ **2015 개정과 다릅니다.** 2015에서는 E가 "60% 미만"이라 미도달 개념이 없었습니다. 2022에서 E의 하한이 40%로 올라가고 그 아래가 분리된 것이 **고교학점제 미이수 판정의 근거**입니다.

## 이런 일을 대신합니다

아래 예시는 경기도교육청이 제시한 **성취평가 절차**의 각 단계에 대응합니다.

### `asa-guide` — 준거를 세웁니다

> 절차상 **① 성취기준 분석 · ② 교수·학습 및 평가에서의 준거 설정 · ④ 평가 척도에서 준거 설정**

성취기준을 지식·이해 / 과정·기능 / 가치·태도로 분석해 **평가 요소**를 뽑고, **학기 단위 성취수준**과 **최소 성취수준 진술문**을 만들고, 평가계획서를 씁니다.

```
"공통국어1 1학기에 다룰 성취기준 정했어. 코드 붙일게.
 평가 요소 뽑고 학기 단위 성취수준까지 만들어줘."

"지필 60 수행 40으로 평가계획 세워줘. 영역별 반영 비율이랑
 논술형 반영 비율, 평가 시기까지 넣어서."

"최소 성취수준 진술문 만들어줘. 미이수 판정 근거로 쓸 거야.
 예방지도·보충지도 계획도 같이."

"교사 3명이 낸 최소 능력자 예상 정답률이야.
 20%p 넘게 벌어진 구간 있으면 짚어줘. 협의 안건으로 쓸게."
```

**놓치기 쉬운 것을 잡아 줍니다.** 공통국어1 14개 성취기준 중 7개를 1학기에 편성하면 6개 영역이 모두 **부분 편성**(1/2, 1/3, 2/3)이 됩니다. 이때 영역별 성취수준을 그대로 병합하면 2학기에 배울 내용까지 1학기 준거에 들어갑니다. 커버리지를 먼저 세고 학기 범위로 **재진술**하도록 안내합니다.

### `asa-item` — 문항을 만듭니다

> 절차상 **③ 평가도구 개발** — 문항정보표 작성, 수행평가 출제계획표 작성, 교과협의회 검토·수정

**선다형**(성취수준별 A~E 표적 5문항 세트) · **서·논술형** · **수행평가 과제**를 만들고, 채점기준표와 성취수준별 분할점수까지 냅니다.

```
"[10공국1-01-02] 로 성취수준별 선다형 5문항 세트 만들어줘."

"이 성취기준으로 수행평가 과제 만들어줘.
 차시별 수업 활동이랑 연결하고 채점기준표까지."

"문항정보표로 정리해줘. 성취기준·예상 난이도·배점·정답 다 넣어서.
 나이스에 입력해야 해."

"교과협의회 검토용으로 이 문항 세트 봐줘.
 수준 구분이 흐린 데 있으면 짚어줘."          ← 검토 모드 (생성 없이 감사만)
```

**난이도 기준은 규칙으로 정해져 있습니다.**
- 선택형 — 목표 수준 최소 능력자의 **약 2/3(66%)** 가 정답을 맞힐 난이도
- 서·논술형 — 목표 수준 학생이 **만점 받을 확률 50%**

### `asa-analyze` — 결과를 되돌립니다

> 절차상 **⑤ 성취 결과 산출 및 보고** — 평가 결과 분석 및 피드백, 평가 결과 처리

정답률과 답지반응 분포로 **평가도구 자체를 검증**하고, 오개념을 추론하고, 미도달 학생을 찾고, 피드백과 세특 기재 틀, 다음 시험 개선안을 냅니다.

```
"1차 지필 결과 분석해줘. 문항정보표랑 정답률, 답지반응 분포 붙일게."

"3번, 예상 난이도는 '쉬움'이었는데 정답률이 45%야. 왜 그럴까?"

"성취수준별 분포 봤을 때 미도달 몇 명이야?
 최소 성취수준 보장지도 대상으로 정리해줘."

"성취수준별로 세특 기재 문구 틀 만들어줘.
 학생별 내용은 내가 채울게."
```

**오개념을 단정하기 전에 네 가지를 먼저 배제합니다** — 문항 결함 · 변별도 저해 선지 · 미학습 · 시험 운영 요인. 그 뒤에야 가설을 세우고, 결론은 항상 "상담이나 후속 형성평가로 확인 필요"로 열어 둡니다.

> **경계 두 가지.**
> **분할점수 확정**은 학업성적관리위원회 심의 사항입니다. 이 도구는 산출·검증·**협의 안건 생성**까지만 합니다.
> **개별 학생의 세특**은 대신 쓰지 않습니다. 학생 실명·식별정보를 받지 않고, 세특은 대입 전형 자료라 교사가 관찰한 사실로 직접 써야 합니다. 만들어 주는 것은 **수준별 서술 틀**입니다.

산출물은 **한글(HWP) 문서**로 나옵니다. 결재·인쇄가 바로 됩니다.

## 실제로 이렇게 나옵니다

`[10공국1-01-02] 논제의 필수 쟁점별로 논증을 구성하고 논증이 타당한지 평가하며 토론한다` 로 문항 세트를 만들면, **문항보다 먼저** 이것이 나옵니다.

### 1단계 — 성취수준별 최소 능력자(MCP)의 수행 특성

| 수준 | 이 수준에 **가까스로** 도달한 학생이 할 수 있는 것 |
|---|---|
| A | 논제에 **알맞은** 필수 쟁점을 파악하여 반박을 갖춘 논증을 구성하고, **여러** 논증 구성 요소를 고려하여 타당성을 **비판적으로** 평가할 수 있다 |
| B | 필수 쟁점을 파악하여 **반박을 갖춘** 논증을 구성하고, 논증 구성 요소를 고려하여 타당성을 비판적으로 평가할 수 있다 |
| C | 필수 쟁점을 파악하여 주장·이유·근거를 갖춘 논증을 **구성**하고, 타당성을 **대략적으로** 평가할 수 있다 |
| D | 필수 쟁점을 **부분적으로** 파악하여 주장·이유·근거를 **제시**하고, 논증의 구성 요소를 일부 구별할 수 있다 |
| E | 교사의 안내나 동료의 도움을 받아 필수 쟁점을 **제한적으로** 파악하고, 간단한 자료에서 주장과 근거를 **찾아낸다** |

인접 수준의 차이를 한 문장으로 말할 수 있어야 통과입니다.

- **A↔B** — 쟁점이 논제에 *알맞은지*까지 판단하는가
- **B↔C** — 논증에 *반박*이 포함되는가 · 평가가 *비판적*인가
- **C↔D** — 논증을 *구성*하는가 vs 요소를 *제시*만 하는가
- **D↔E** — 스스로 파악하는가 vs 도움받아 *찾아내는* 수준인가

### 2단계 — 이 진술이 문항의 출제 범위가 됩니다

```
A 최소 능력자의 특성  ──┐
                        ├─  이 사이가 'B를 대표하는 문항'의 출제 범위
B 최소 능력자의 특성  ──┘
```

### 3단계 — 그다음에 문항

**A 수준 문항** — 찬반 4개 발언에 서로 다른 논증 요소(근거의 인과성 / 근거의 충분성 / 예상 반론 반박 / 허수아비 공격)를 교차 적용해야 풀립니다. `<보기>`는 격률 이름을 밝히지 않고 줄글로만 서술합니다.

**E 수준 문항** — 짧은 발언 하나에서 주장을 고릅니다. **지문에 답이 그대로 적혀 있습니다.**

> **찬성**: 저희는 학교 매점에서 탄산음료를 팔지 말아야 한다고 생각합니다.
> **왜냐하면** 지난달 보건실 설문에서 10명 중 6명이 하루 두 캔 넘게 마신다고 답했기 때문입니다.
>
> **문. 위 발언에서 '주장'에 해당하는 것은?**
> ② 학교 매점에서 탄산음료를 팔지 말아야 한다.

E 수준 문항을 "조금 쉬운 문항"으로 만들면 실제로는 C~D 수준이 되고, **최소 성취수준 판별이 무너집니다.** 이 도구는 국어과에서 E의 바닥을 "지문에 답이 명시되는 지점"으로 규정해 두고 그것을 지킵니다.

### 3. 성취수준 데이터 만들기 ★

**저장소에는 성취수준 원문이 들어 있지 않습니다.** 한국교육과정평가원의 저작물이라 재배포하지 않고, 각자 로컬에서 만들도록 했습니다.

아래 두 자료를 내려받아 저장소 폴더에 두세요. 둘 다 **`.hwp`** 를 권합니다. PDF는 표가 페이지를 넘을 때 셀이 깨집니다(공통과목 '읽기' 영역 E 수준에서 실제로 깨집니다).

| 자료 | 발행 |
|---|---|
| 2022 개정 교육과정에 따른 고등학교 **국어과 공통과목 성취수준** | 한국교육과정평가원 (2024) |

파일 이름은 `subject/subject.yaml` 의 `sources` 항목과 맞춰 주세요. 다르면 그 항목을 고치면 됩니다.

```bash
python scripts/build_refs.py        # 성취수준 추출

```

성공하면 이렇게 나옵니다.

```

공통국어2                  15                6
```

## 다루는 과목 (11개)

| 구분 | 과목 | 성취기준 |
|---|---|---|
| 공통 | 공통국어1 · 공통국어2 | 14 · 15 |
| 일반선택 | 화법과 언어 · 독서와 작문 · 문학 | 15 · 15 · 12 |
| 진로선택 | 주제 탐구 독서 · 문학과 영상 · 직무 의사소통 | 7 · 10 · 10 |
| 융합선택 | 독서 토론과 글쓰기 · 매체 의사소통 · 언어생활 탐구 | 7 · 7 · 7 |

전 과목 **성취도 5단계(A~E)** 이고 **석차등급 5등급**도 산출합니다.

성취도 단계를 정하는 것은 과목 유형(공통/일반선택/진로선택/융합선택)이 아니라 **교과(군)** 입니다. 국어 교과군은 융합선택까지 전부 5단계이고, 3단계(A~C)는 체육·예술 교과군과 공통과목 과학탐구실험뿐입니다. 석차등급 미산출 예외도 **사회·과학 교과군의 융합선택 9과목**만 해당하므로 국어과는 해당하지 않습니다.

> ⚠ **영역별 성취수준은 공통과목에만 있습니다.** 평가원은 선택과목 9종에 대해서는 성취기준별 성취수준만 개발했습니다. 국어 선택과목은 **내용 영역 구분 자체가 없어서** 성취기준 코드의 영역 자리가 전부 `01`입니다(`[12화언01-03]`).
>
> 평가원은 이 경우 "성취기준별 성취수준을 바탕으로 학기 단위 성취수준 개발 방법을 준용하여 개발해 활용하라"고 안내합니다. 그래서 **학기 단위 성취수준을 만드는 경로가 공통과목과 선택과목에서 갈립니다.** 스킬이 알아서 갈라 처리하지만, 알고 계시면 결과를 검토하실 때 도움이 됩니다.

```
  cut-score.md       고정/추정 분할점수 절차와 검증 규칙 C1~C6

  difficulty-levers.md   ★ 성취수준을 가르는 국어과 난이도 변수
```

**왜 이렇게 나눴나** — 성취율, 분할점수 산출 절차, MCP 개념 같은 **제도 규칙은 교과와 무관**합니다. 교과마다 다른 건 성취기준과 "무엇이 난이도를 만드는가"뿐입니다. 그래서 둘을 갈라 놓았습니다. 수학과 버전을 만들어도 엔진은 그대로 쓰고, 나중에 엔진이 개선되면 그것도 받아올 수 있습니다.

```bash
python scripts/init_subject.py --id math --name "수학과"
```

가장 중요하고 어려운 건 `difficulty-levers.md` — **그 교과에서 무엇이 성취수준을 가르는가**를 정리하는 문서입니다.

| | 난이도를 만드는 변수 |
|---|---|

## 자주 나오는 질문

**Q. 성취수준 데이터를 왜 저장소에 안 넣었나요?**
교육부·평가원·시도교육청의 저작물이기 때문입니다. 공개 저장소에 재배포할 근거가 확인되지 않아 각자 빌드하는 방식으로 했습니다. 해당 자료가 **공공누리 제1유형(출처표시)** 으로 확인되면 함께 배포하도록 바꿀 예정입니다.

**Q. 분할점수를 스킬이 정해 주나요?**
아니요. **산출·검증·협의 안건 생성까지만** 합니다. 분할점수 확정은 **학업성적관리위원회 심의 사항**입니다. 추정분할점수를 쓸 경우 심의 시점도 정해져 있습니다 — 수행평가 실시 전, 1차 지필 전, 2차 지필 전, 학기말 최종 산출 후.

**Q. 미도달 학생 비율이 높으면 E 분할점수를 낮춰도 되나요?**
안 됩니다. 정책 문서가 명시적으로 금지합니다. 이수 판정의 신뢰성이 무너집니다. 이 도구도 규칙(R2)으로 막고 경고합니다.

**Q. 학생 성적 데이터를 넣어도 되나요?**
**성적일람표 원본은 안 됩니다.** `asa-analyze` 는 **문항 단위 집계와 익명 분포만** 받습니다. 실명이 든 자료를 주면 스킬이 분석을 시작하지 않고 어느 열을 지워야 하는지 짚어 익명화를 먼저 요청합니다. 문항 분석만 하실 거라면 **학생 행 자체가 필요 없습니다.** 위 '시작하기 전에' 와 [core/privacy.md](core/privacy.md) 참조.

**Q. 다른 시도교육청인데 쓸 수 있나요?**
됩니다. `subject/subject.yaml` 의 `jurisdiction` 블록만 고치세요. 기본값이 경기도교육청 지침(선택형=오지선다, 서답형=논술형)으로 되어 있습니다.

**Q. 2015 개정 자료도 되나요?**
성취수준 체계가 달라 그대로는 안 됩니다. E 구간이 다르고(위 경고 참조), 2015의 **평가기준(상/중/하)** 은 2022에서 **성취기준별 성취수준(A~E)** 으로 바뀌었습니다. 미이수 판정 근거가 걸린 부분이라 섞으면 안 됩니다.
