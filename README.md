# asa-skills — 성취평가제 교사 지원 스킬 · 국어과

2022 개정 교육과정 성취평가제에 따라 **평가 준거를 설정하고, 평가 문항을 개발하고, 평가 결과를 분석하는** 것을 돕는 Claude Code 스킬 모음이다.

> **이 저장소는 국어과 버전이다.** 다른 교과 버전은 이 저장소를 포크해서 만든다 → [FORKING.md](FORKING.md)

---

## 스킬

| 스킬 | 하는 일 |
|---|---|
| **`asa-guide`** | 제도 이해 · 성취기준 분석 → 평가 요소 · 학기 단위 성취수준 진술 · 최소 성취수준 진술문 · 평가계획서 |
| **`asa-item`** | 선다형 / 서·논술형 / 수행평가 문항 개발 · 채점기준표 · 분할점수 산출 |
| **`asa-analyze`** | 문항 분석 · 성취수준 분포 · 오개념 추론 · 개인별 피드백 · 차기 평가도구 개선 |

세 스킬 모두 **검토 모드**를 내장한다. 이미 만들어 둔 문항·채점기준·성취수준 진술문을 넣으면 감사만 수행한다(교과협의회 상호 검토 대행).

최종 산출물은 **한글(HWP/HWPX) 문서**로 나온다. 결재·인쇄가 바로 가능하다.

---

## 구조

```
skills/     asa-guide · asa-item · asa-analyze      ← 엔진 (교과 중립)
core/       성취평가제 규칙 · 성취수준 진술 · 분할점수 · 결과 분석   ← 엔진 (교과 불변)
subject/    국어과 팩 — 포크 시 이 디렉터리만 교체한다
scripts/    빌드 · 검증 · 자료 수집
```

**교과 지식은 `subject/` 안에만 있다.** 그래서 다른 교과로 포크한 뒤에도 `git merge upstream/main`으로 엔진 개선을 계속 받을 수 있다.

## 시작하기

### 1. 설정

```bash
cp .env.example .env
# .env 에 KICE 학생평가지원포털(stas.moe.go.kr) 계정을 입력
```

### 2. 성취수준 데이터 빌드

저작권 때문에 성취수준 원문과 예시문항은 저장소에 포함하지 않는다. 원자료를 로컬에 두고 빌드한다.

```bash
python scripts/build_refs.py       # subject/data/ 생성
python scripts/validate_subject.py # 교과 팩 적합성 검사
```

필요한 원자료는 `subject/subject.yaml`의 `sources` 블록에 명시되어 있다.

### 3. 사용

```
/asa-guide    한 학기 평가계획을 세우고 싶어. 공통국어1 1학기야.
/asa-item     [10공국1-01-02] 로 성취수준별 선다형 5문항 세트 만들어줘.
/asa-analyze  1차 지필평가 결과 분석해줘. 문항정보표랑 정답률 첨부했어.
```

## 저작권

`core/`, `skills/`, `subject/`의 문서는 이 저장소의 저작물이다.
