# 국어과 오답·오개념 패턴

> **교과 특수 문서.** 포크 시 해당 교과의 오개념으로 다시 쓴다.
> `skills/asa-analyze`가 답지반응 분포를 해석할 때 이 문서를 참조한다.
>
> 목적: "예상 난이도와 실제 정답률의 차이가 큰 문항"이 나왔을 때, **왜 그랬는지**를
> 답지반응 분포로부터 추론하기 위한 가설 목록이다. 확정 진단이 아니라 **교사가 학생과
> 상담해 확인할 후보**를 제시하는 데 쓴다.

## 2. 영역별 패턴

### 듣기·말하기
- 협력의 원리와 공손성의 원리를 **뒤섞어** 적용 (양·질·관련성·태도 ↔ 요령·관용·칭찬·겸양·동의)
- **화자와 청자의 입장을 바꿔** 격률을 적용 (관용의 격률을 상대에게 적용하는 식)
- 담화 관습을 **개인의 성격 문제로** 환원

### 읽기
- 논증의 **결론과 근거를 뒤바꿔** 파악
- 필자의 관점과 **인용된 타인의 관점**을 구분하지 못함
- 주제 통합적 읽기에서 자료 간 **공통점만 보고 차이·긴장 관계를 놓침**
- 사실과 의견의 경계를 흐리게 읽음

### 쓰기
- 독자 분석을 **인구통계 나열**로 대체 (나이·성별만 적고 태도·관심사를 다루지 않음)
- 근거의 **타당성**과 **양**을 혼동 (많이 쓰면 타당하다고 여김)
- 고쳐쓰기를 **맞춤법 교정**으로만 이해 (내용·구성 차원의 수정 부재)

### 문법
- 음운 변동에서 **표기와 발음을 혼동**
- 규칙의 **예외 사례를 규칙으로** 일반화
- 형태소 분석 시 **어간과 어근**, **어미와 접사** 혼동
- 문법 요소의 형태는 아나 **표현 효과**를 설명하지 못함

### 문학
- 화자·서술자를 **작가 본인**으로 동일시
- **갈래적 특성 없이** 내용만 요약
- 감상을 **줄거리 재진술**로 대체
- 사회·문화적 맥락을 **작품 밖 배경지식**으로만 처리하고 작품 내적 근거와 연결하지 못함
- 주체적 해석을 **근거 없는 주관적 감상**으로 오해

### 매체
- 매체 **형식적 특징**만 나열하고 생산자의 관점·의도를 파악하지 못함
- 선택·배제·강조 중 **강조만** 파악
- 매체 자료의 신뢰성을 **출처의 유명도**로만 판단

## 4. 해석 시 유의

**정답률이 낮다고 모두 오개념은 아니다.** 다음을 먼저 배제한다.

1. **문항 결함** — 복수정답·정답 없음·발문 모호
2. **변별도 저해 선지** — 응답률이 극단적으로 낮은 선지는 오답으로 기능하지 못하고 실질 선택지 수를 줄인다
3. **미학습** — 수업에서 다루지 않았거나 시간이 부족했던 내용
4. **시험 운영 요인** — 시간 부족(뒷번호 문항 정답률 급락), 지시 오류

이 넷을 배제한 뒤에야 오개념 가설을 세운다. `core/result-analysis.md`의 분석 절차를 따른다.

**그리고 답지반응 분포는 가설을 좁힐 뿐 확정하지 못한다.** 최종 확인은 학생과의 상담 또는 후속 형성평가로 한다.
