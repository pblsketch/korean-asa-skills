# 성취평가 준거 설정

## 이 스킬이 다루는 것

성취평가 5단계 절차 중 **1·2단계와 4단계**, 그리고 제도 이해 전반이다.

```
1단계  성취기준 분석              ← 이 스킬
2단계  교수·학습 및 평가에서의 준거   ← 이 스킬 (학기 단위 성취수준)
3단계  평가도구 개발              → asa-item
4단계  평가 척도에서 준거 (분할점수)  ← 이 스킬 (절차 안내·검증)
5단계  결과 산출·보고             → asa-analyze
```

**핵심 원칙**: 준거는 **교수·학습 투입 전**에 확정한다. 학기가 시작된 뒤에 만드는 성취수준은 준거가 아니라 사후 정당화다.

## 시작 전

```bash
python scripts/lookup_standard.py --list
```

실패하면 `python scripts/build_refs.py` 를 먼저 안내한다.

**과목을 특정하면 반드시 이 두 가지를 확인한다.**

| 확인 | 왜 |
|---|---|
| 평정 단계 (5단계 / 3단계) | 만들 수준 수가 달라진다 |
| **영역별 성취수준 유무** | 학기 단위 성취수준을 만드는 **경로가 완전히 갈린다** |

## 작업 ① 제도 질문에 답하기

`core/asa-rules.md` 를 근거로 답한다. 추측하지 않는다.

자주 나오는 질문과 근거 위치
- 성취율·성취도, 어느 과목이 몇 단계인가 → §2
- 문항 난이도 2/3·50% 규칙 → §4
- 금지 규칙 R1~R7 → §6
- 고교학점제 이수 기준·미이수 처리 → §2, §8
- 분할점수 → `core/cut-score.md`
- 성취수준 진술 원리 → `core/level-writing.md`

**2015 개정과 헷갈리는 지점을 먼저 짚어 준다.**
- 2022 개정에서 E는 40~60%이고 그 아래가 미도달이다. 2015에서는 E가 60% 미만이라 미도달 개념이 없었다
- 단계를 정하는 것은 과목 유형이 아니라 **교과(군)** 다. 2015에서 진로선택이 3단계였던 것과 다르다

## 작업 ② 성취기준 분석 → 평가 요소 도출

```bash
python scripts/lookup_standard.py "[코드]" --with-area
```

1. 성취기준을 **지식·이해 / 과정·기능 / 가치·태도** 로 분해한다
2. 성취기준 해설과 적용 시 고려 사항을 반영해 학습 내용의 범위와 수준을 확인한다
3. 평가 요소를 도출한다 — 성취기준 도달의 **증거로 학생이 보여주기를 기대하는 핵심 내용**
4. 요소별로 적합한 평가 방법(지필 선택형/논술형, 수행 유형)을 배정한다

**가치·태도를 빠뜨리지 않는다.** 성취기준에 명시돼 있으면 평가 대상이다. 단 관찰 가능한 수행으로 조작적 정의해야 채점할 수 있다.

**평가 요소 개수 조절** — 너무 많으면 성취수준 확인의 효율이 떨어지고, 너무 적으면 모든 성취수준을 확인할 수 없다. 학습자가 "무엇을 어떻게 수행할지" 판단할 수 있는 용어로 쓴다.

## 작업 ③ 학기 단위 성취수준 진술 ★

**이 스킬의 가장 중요한 작업이다.** 수업·평가·기록의 최종 준거가 된다.

### 먼저 경로를 가른다

```bash
python scripts/lookup_standard.py --list   # '영역별 성취수준' 열 확인
```

| 영역별 성취수준 | 경로 |
|---|---|
| **있음** (보통 공통과목) | 국가 개발본을 재료로 §3의 세 방식(㉮㉯㉰) 중 선택 |
| **없음** (보통 선택과목) | **성취기준별 성취수준에서 직접 종합**. ㉯ 재구성 방식을 준용 |

> 한국교육과정평가원은 공통과목에만 영역별 성취수준을 개발했다. 또한 내용 영역이 구분되지 않은 선택과목은 영역 단위 자체가 없다.
> KICE는 이 경우 "성취기준별 성취수준을 바탕으로 학기 단위 성취수준 개발 방법을 준용하여 개발해 활용하라"고 지시한다.
> 없는 재료를 있는 것처럼 지어내지 않는다.

### 진술 방식 (`core/level-writing.md` §3)

| 방식 | 언제 |
|---|---|
| ① 성취기준별 중심 | 학기당 성취기준 수가 적을 때. 준거로 직접 쓰기 쉽지만 전체 조망이 어렵다 |
| ②㉮ 범주별 병합 | 쉽다. 단 범주 비중이 다른 교과에서 덜 중요한 범주가 과대 표현될 수 있다 |
| ②㉯ 재구성 | 중복 표현을 묶어 간결하게. **영역별 성취수준이 없는 과목의 기본 경로** |
| ②㉰ 교과 역량 중심 | 교육 목표와 일관. 역량이 고루 등장하는지 점검할 것 |

사용자가 방식을 말하지 않으면 과목 특성을 보고 **추천하고 확인받는다.**

### 학기 편성 범위를 먼저 확인한다 ★

**학기에 어느 성취기준이 편성되는지는 교사·교과협의회가 정한다. 스킬이 정하지 않는다.** 사용자에게 묻는다.

편성이 정해지면 영역별 커버리지를 센다.

```
영역 01  1/2 부분    영역 04  1/3 부분    …
```

> ⚠ **부분 편성 영역이 있으면 영역별 성취수준을 그대로 병합하면 안 된다.**
> 학기에 없는 성취기준의 내용까지 준거에 들어간다. 영역별 성취수준은 **범주 구분의 틀**로만 쓰고,
> 내용은 **편성된 성취기준별 성취수준**에서 가져와 재진술한다. (`core/level-writing.md` §3 ②)

### 진술 규칙

- 부사어 위계: `A 정확하게 · B 비교적 정확하게 · C 대략적으로 · D 부분적으로 · E 제한적으로`
- **부사어만 다르고 내용이 같으면 수준 구분이 아니다.** 본체는 지식 위계 / 과정·기능 맥락 / 가치·태도 내면화의 실질적 차이여야 한다
- 관찰 가능한 외현 동사를 쓴다
- 모호·추상적, 비교육적·부정적 표현을 쓰지 않는다 (학생·학부모에게 공지되고 기록의 근거가 된다)

양식: `core/templates/semester-levels.md`

## 작업 ④ 최소 성취수준 진술문 + 보장지도

고교학점제 미이수 판정의 근거다. **실무 리스크가 가장 큰 작업이다.**

### Range PLD ≠ Target PLD

```
성취수준 E 진술문        40~60% 구간 전체        (Range PLD)
최소 능력의 수행 특성    정확히 40% 지점         (Target PLD)  ★
```

E 진술문을 그대로 옮겨 적으면 안 된다. 40% 지점까지 내려가야 한다.

> 예 — E: "간단한 다항식의 사칙연산을 할 수 있다"
> → 최소 능력의 수행 특성: "㉮ 간단한 다항식의 **덧셈과 뺄셈**을 할 수 있다"

### 구성

`영역` + `영역별 성취수준(E)` + `성취기준별 성취수준(E)` + `최소 능력의 수행 특성(㉮㉯㉰)`

영역별 성취수준이 없는 과목은 그 칸을 비우고 성취기준별 성취수준(E)에서 직접 도출한다.

### 이어서 반드시 함께 낸다

- **진단·형성·총괄 각 단계**의 미도달 예상 학생 식별 방안
- **예방지도**(미도달 예상) / **보충지도**(미도달) 계획
- 지필·수행에서 최소 성취수준을 확인할 문항·과제 요건
  - 지필: 성취율 40%를 판별할 수 있는 문항 포함
  - 수행: 40% 성취율에 해당하는 채점기준과 연계, **기본점수는 그보다 낮게** (R1)

양식: `core/templates/min-level-statement.md`

## 작업 ⑤ 분할점수

산출 자체보다 **절차와 공지 시점**을 지키는 것이 중요하다. `core/cut-score.md` 전체를 따른다.

- 고정 vs 추정 결정 → **학기 초 평가 계획 단계**에서 하고 학업성적관리위원회 심의
- 추정분할점수는 지필 7단계 / 수행 6단계 절차를 밟는다
- 교사별 예상 정답률을 받으면 **규칙 C1~C6 를 전부 검증**한다
  - 5% 단위(E만 1% 허용) · 하위 ≤ 상위 · 쉬움 ≥ 보통 ≥ 어려움
  - 수준 간 20%p 이상 → 경고 · 교사 간 20%p 이상 → **협의 필수**
  - 2라운드 이상
- 20%p 경고가 뜨면 값을 억지로 맞추지 말고 **왜 갈렸는지 논의할 안건**을 만들어 준다
- ⚠ 미도달 비율을 줄이려 E 분할점수를 임의로 낮추지 않는다 (R2)

수행평가는 채점기준표에서 분할점수가 자동으로 나온다 — **각 수준 MCP가 평가 요소별로 받는 점수의 합**.

## 작업 ⑥ 학기 평가계획서

①~⑤의 산출물을 담는 그릇이다.

- 평가의 종류와 반영 비율 (지필 1·2차 / 수행 영역별, 논술형 반영 비율 포함)
- 영역별 만점·반영 비율, 교육과정 성취기준, 평가 요소, 평가 시기
- 분할점수 산출 방식
- 최소 성취수준 보장지도 운영 계획
- 심의·결재·공지 일정 체크리스트

**행정 절차를 함께 안내한다** (`core/asa-rules.md` §7)
- 학기 초 학업성적관리위원회 심의 · 학교장 결재 · 가정통신문
- 분할점수는 **평가 시행 전** 공지 (수행 실시 전 / 1차 지필 전 / 2차 지필 전 / 학기말 산출 후)

## 자체 검증

내놓기 전에 확인한다.

- [ ] 인접 수준의 차이를 **한 문장으로 말할 수 있는가** — 못 하면 다시 쓴다
- [ ] 차이가 부사어뿐인 곳은 없는가
- [ ] 세 범주(지식·이해 / 과정·기능 / 가치·태도)가 모두 반영되었는가
- [ ] 관찰 가능한 외현 동사를 썼는가
- [ ] 모호·추상적, 비교육적·부정적 표현이 없는가
- [ ] 영역 간 수준 설정 기준이 일관되는가
- [ ] 해당 학기 성취기준 **전체**를 포괄하는가
- [ ] 성취기준의 교육과정 범위를 벗어나지 않았는가
- [ ] 최소 성취수준 진술문이 Range 가 아닌 **Target(40% 지점)** 을 기술했는가
- [ ] **없는 영역별 성취수준을 지어내지 않았는가**

## 출력

한글 문서로 낸다. 페이로드 형태와 함정은 `skills/asa-item/SKILL.md` 7단계와 동일하다.
핵심만: 키는 `operations`/`type`, 기존 파일은 `allow_overwrite: true`, **반드시 `ops_applied` 확인**.

### 인계 파일 ★ — `asa-item` 이 읽는다

학기 단위 성취수준이나 평가계획을 만들었으면 **반드시** `.work/plan/<과목id>_<학기>.json` 에 남긴다.
학기 단위 성취수준은 평가도구 개발의 준거이므로, 이걸 남기지 않으면 `asa-item` 이 준거 없이 문항을 만들게 된다.

```json
{
  "course_id": "<과목 id>", "semester": "2025-1",
  "standards": ["[코드]", "…"],
  "area_coverage": {"01": {"selected": 1, "total": 2}, "…": {}},
  "semester_levels": {
    "A": {"지식·이해": "…", "과정·기능": "…", "가치·태도": "…"},
    "B": {}, "C": {}, "D": {}, "E": {}
  },
  "elements": {"[코드]": ["평가 요소 1", "평가 요소 2"]},
  "min_level": {"[코드]": ["㉮ …", "㉯ …"]},
  "assessment_plan": {"지필": {"1차": {"반영비율": 30}}, "수행": {}}
}
```

만든 부분만 채우고 나머지는 생략한다. 사용자에게 파일 경로를 알려 준다.

## 모드

### `review` — 감사만 수행
이미 만든 학기 단위 성취수준·최소 성취수준 진술문·평가계획서를 받아 **생성하지 않고 검증만** 한다.
위 체크리스트 전부 + 부사어 위계 붕괴(예: C가 D보다 약한 부사어) + 성취기준↔평가요소 추적성 끊김을 본다.
발견 → 근거(어느 규칙 위반인지) → 수정 제안 순으로 보고한다.

## 하지 말 것

- 영역별 성취수준이 없는 과목에 대해 **있는 척 지어내기**
- E 진술문을 그대로 옮겨 최소 성취수준 진술문이라 하기
- 부사어만 바꿔 수준을 나눈 척하기
- 분할점수를 사용자 대신 **확정**하기 — 학업성적관리위원회 심의 사항이다. 산출·검증·안건 생성까지만
- 학생 실명·식별정보를 다루기
